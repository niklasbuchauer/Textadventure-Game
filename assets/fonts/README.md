# Bundled Fonts

Place optional bundled font files here to stabilize symbol rendering across machines.

Supported preferred filenames:

- `NotoSans-Regular.ttf`
- `NotoSans-Bold.ttf`
- `NotoSans-Italic.ttf`
- `NotoSans-BoldItalic.ttf`
- `NotoSansMono-Regular.ttf`
- `NotoSansMono-Bold.ttf`

Alternative fallback filenames also recognized:

- `DejaVuSans.ttf`
- `DejaVuSans-Bold.ttf`
- `DejaVuSans-Oblique.ttf`
- `DejaVuSans-BoldOblique.ttf`
- `DejaVuSansMono.ttf`
- `DejaVuSansMono-Bold.ttf`
- `DejaVuSansMono-Oblique.ttf`
- `DejaVuSansMono-BoldOblique.ttf`

Notes:

- Keep licensing information for any bundled font files in this folder.
- If no bundled fonts are present, runtime falls back to best-available system fonts.
